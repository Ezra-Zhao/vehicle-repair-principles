# 04 术语表：保养维修中英对照

> 配合《养车避坑体系》使用。表述为本站重写。

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Engine Oil Viscosity | 机油黏度 | 如 0W-20，决定机油冷启动流动性和高温油膜厚度，按手册选用 |
| Oil Film | 油膜 | 机油在摩擦面之间形成的润滑膜，冷启动未建立前磨损最剧烈 |
| Boundary Lubrication | 边界润滑 | 油膜未完全建立时的半干摩擦状态，冷启动瞬间即处此状态 |
| Detergent / Dispersant | 清洁分散剂 | 机油添加剂，把油泥积碳颗粒分散悬浮带走，机油变黑多是它在干活 |
| LSPI (Low-Speed Pre-Ignition) | 低速早燃 | 低转速大负荷下混合气提前自燃，对活塞是打击性损伤，拖挡易诱发 |
| Parking Pawl | 驻车棘爪 | P 挡锁止齿轮的小金属爪，坡道先挂 P 会让它承受整车重量 |
| Neutral Coasting | 空挡滑行 | N 挡滑行，自动变速箱润滑跟不上且失去发动机制动，又不省油 |
| OBD2 (On-Board Diagnostics II) | 车载诊断系统 | 统一标准的故障诊断接口，读码器可读取故障码与数据流 |
| DTC (Diagnostic Trouble Code) | 故障码 | 电脑记录的故障代码，是诊断的起点不是结论 |
| ATF (Automatic Transmission Fluid) | 自动变速箱油 | 变速箱专用油液，混动 P410 常用 Toyota WS 规格，不可混用 |
| DOT3 / DOT4 | 刹车油规格 | 刹车油标准，亲水吸湿，含水量超标则沸点下降 |
| Brake Fade | 热衰减 | 刹车过热导致制动力下降，刹车油汽化是原因之一 |
| Coolant | 冷却液 / 防冻液 | 发动机与逆变器散热用液体，防腐添加剂耗尽需更换 |
| EGR Carbon Buildup | EGR 积碳 | 废气再循环带来的碳烟在冷却器与进气道沉积，第三代 Prius 高发 |
| Short Trip | 短途行驶 | 发动机未充分热透的短距离行驶，积碳与机油稀释的主因之一 |
| DOT Date Code | 轮胎生产日期码 | 胎壁后四位数字表生产周/年，轮胎超 6 年建议更换不看花纹 |
| Bushing | 衬套 | 悬挂等处的橡胶缓冲件，老化开裂导致异响与跑偏 |
| Ball Joint | 球头 | 转向/悬挂的球形铰接件，旷量大了会吃胎 |
| Tire Feathering / Uneven Wear | 吃胎 / 偏磨 | 轮胎异常磨损，多由定位失准或球头衬套旷量引起 |
