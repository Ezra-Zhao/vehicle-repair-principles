# 03 术语表：丰田混动 / Prius 中英对照

> 配合《丰田混动系统全解》使用。表述为本站重写。

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Hybrid Synergy Drive (HSD) | 混动协同驱动 | 丰田混动系统的总称，核心是功率分流式混联结构 |
| Power Split Device | 功率分流装置 | 把发动机功率分成机械直驱和发电两路的核心机构，就是那组行星齿轮 |
| Planetary Gear Set | 行星齿轮组 | 太阳轮+行星轮+行星架+齿圈组成的齿轮机构，三个构件转速互相约束 |
| Sun Gear | 太阳轮 | 行星齿轮组中心的小齿轮，Prius 里连接 MG1 |
| Planet Gear | 行星轮 | 围绕太阳轮转动的几个小齿轮，同时咬合太阳轮和齿圈 |
| Planet Carrier | 行星架 | 固定行星轮转轴的支架，Prius 里连接发动机曲轴 |
| Ring Gear | 齿圈（内齿圈） | 最外圈的内齿齿轮，Prius 里连接 MG2 与车轮 |
| MG1 (Motor Generator 1) | 1 号电机/发电机 | 小电机，主要负责发电和调节发动机转速（实现无级变速） |
| MG2 (Motor Generator 2) | 2 号电机/发电机 | 大电机，直接驱动车轮，减速时反转为发电机回收能量 |
| e-CVT | 电子无级变速 | 丰田对这套行星齿轮+双电机结构的叫法，无钢带、无锥轮、无挡位 |
| Transaxle | 变速驱动桥 | 变速箱+驱动桥做成一体，Prius 的 P410 即混动变速驱动桥 |
| P410 | P410 变速驱动桥 | 第三代 Prius（2010–2015）使用的混动变速驱动桥代号 |
| Atkinson Cycle | 阿特金森循环 | 膨胀比大于压缩比的发动机循环，热效率高、动力弱，适合混动 |
| Regenerative Braking | 再生制动 / 能量回收 | 减速时用电机当发电机，把动能转成电能充回电池 |
| Traction Battery | 动力电池 / 牵引电池 | 驱动电机用的高压电池组，第三代 Prius 为镍氢电池 |
| NiMH Battery | 镍氢电池 | 第三代 Prius 动力电池类型，皮实耐用、能量密度低于锂电 |
| State of Charge (SOC) | 荷电状态 | 电池当前电量百分比，混动系统通常把它维持在中间区间以延寿 |
| Inverter | 逆变器 | 把电池直流电变成驱动电机用交流电的大功率电子模块 |
| DC-DC Converter | 直流变换器 | 把高压电降为 12V，给小电瓶和车载低压设备供电 |
| Reduction Gear | 减速齿轮 | P410 中给 MG2 配的减速齿轮，让电机更小更快、扭矩经齿轮放大 |
| Final Drive | 主减速器 / 终传 | 把动力最终传向车轮的那组齿轮，决定总减速比 |
| Series Hybrid | 串联式混动 | 发动机只发电、车轮只由电机驱动，如增程式 |
| Parallel Hybrid | 并联式混动 | 发动机和电机都能直接驱动车轮 |
| Power-Split Hybrid | 功率分流式混动 | 发动机功率一路机械直驱、一路发电，丰田 HSD 路线 |
| EGR (Exhaust Gas Recirculation) | 废气再循环 | 把部分废气送回进气道以降燃烧温度，积碳是其常见副作用 |
| Head Gasket | 气缸垫 | 缸体与缸盖之间的密封垫，冲掉会导致冷却液消耗、抖动 |
| Brake Actuator | 制动执行器 | Prius 电子制动系统的液压执行单元，内含电动泵与蓄压器 |
| ECB (Electronically Controlled Brake) | 电子控制制动 | 踏板与液压解耦、电脑分配制动力的线控制动系统 |
| Accumulator | 蓄压器 | 储存液压压力的容器，内泄会导致打压泵频繁工作 |
| Inverter Coolant Pump | 逆变器冷却液泵 | 给逆变器独立冷却回路打循环的电动水泵 |
| 12V Auxiliary Battery | 12V 小电瓶 | 负责唤醒电脑与高压系统的普通低压电瓶，没电则全车无反应 |
| Engine Start-Stop | 发动机启停 | 混动系统根据工况自动启停发动机，省掉怠速油耗 |
| Parking Pawl | 驻车棘爪 / P 挡锁止机构 | P 挡时卡住齿轮防止车辆移动的机械锁止件 |
