# 05 术语表：DIY 修车中英对照

> 配合《普通人 DIY 修车入门》使用。表述为本站重写。

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Jack Stand | 安全支架 | 顶车后真正承重的支撑架，千斤顶只负责顶起，人钻车底前必须用它撑住 |
| Torque Wrench | 扭力扳手 | 按规定扭矩拧紧螺丝的扳手，DIY 从野路子变正规军的分水岭 |
| Torque Spec | 扭矩规格 | 厂家规定的螺丝拧紧力矩，如轮胎螺丝、火花塞都有标准值 |
| OBD2 Scanner | OBD2 读码器 | 接诊断接口读取故障码与数据流的小设备，诊断的起点 |
| Service Plug | 维修塞（高压） | 混动高压系统的维修断开塞，非专业人员不动 |
| High-Voltage Cable (Orange) | 高压线束（橙色） | 橙色外皮即高压回路标识，200V 量级，DIY 禁区 |
| Multimeter | 万用表 | 测电压/电阻/通断的基础电工工具，查电路必备 |
| Impact Wrench | 冲击扳手 / 风炮（电动） | 靠冲击力松紧螺丝的电动工具，拆轮胎螺丝省力神器 |
| Brake Caliper | 刹车分泵 / 卡钳 | 夹住刹车盘产生制动力的部件，换刹车片时需将其回位 |
| Brake Pad | 刹车片 | 摩擦片，磨损到极限厚度必须更换 |
| Oxygen Sensor (O2 Sensor) | 氧传感器 | 监测排气中氧含量、反馈修正喷油量的传感器，爱坏也好换 |
| Spark Plug | 火花塞 | 点燃混合气的部件，按点火顺序更换，注意安装扭矩 |
| Cabin Air Filter | 空调滤芯 | 过滤进车厢空气的滤芯，一般一年一换，DIY 极易 |
| Engine Air Filter | 空气滤芯 | 过滤进发动机空气的滤芯，脏了费油又没劲 |
| TIS (Technical Information System) | 丰田技术信息系统 | 丰田原厂维修资料库，可订阅查询扭矩、电路图与拆装流程 |
