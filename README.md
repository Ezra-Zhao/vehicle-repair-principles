# 车辆维修原理知识库 · Vehicle Repair Principles

> 吸取百家之所长，集大成于一处。
> 把 7 个优质汽车视频 / 频道的核心观点，用自己的话重写成一套**能直接拿去学的完整知识体系**——不是链接堆砌，是从原理讲到实操的系统笔记。

适合谁：想真正搞懂车是怎么工作的车主、想自己动手做基础保养的人、买二手车不想被忽悠的人。
我写它的起因：开一台 2011 第三代 Prius，想把它彻底搞明白——从混动怎么工作，到老车怎么养。
